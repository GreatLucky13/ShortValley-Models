# ShortValley Models

Public Supertonic model files for ShortValley Web.

- GitHub Releases provide versioned manual downloads and the SHA-256 manifest.
- `models/supertonic-v1.0.0/` is stored with Git LFS and is used by the browser installer because GitHub's media endpoint supports cross-origin downloads.
- ShortValley validates every downloaded file before writing `installed.json` to the selected local folder.
